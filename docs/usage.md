# 使用指南

## 账号

首次启动只创建超级管理员，默认用户名为 `admin`。管理员登录后只能管理普通用户，不能使用收藏、标签、分享、模型配置或 MCP。

管理员创建普通账号并设置至少 16 字符的登录密钥。登录可填写用户名和密钥，也可只填写唯一的密钥。用户名区分大小写。普通用户在设置中修改自身密钥后，旧会话和旧 MCP 密钥立即失效。

管理员可搜索、查看、编辑、停用和永久删除普通用户。保存账号修改后，该用户需重新登录。删除账号会删除其服务器上的收藏、标签、模型配置、会话和分享，无法撤销。

## 收藏与标签

收藏包含 `raw`（原文）、`tags`、`description`（说明）和 `score`。原文保留原始内容，不清洗 URL 参数，同一用户内原文唯一。说明可空，评分范围为 `[0,1]`，默认 `0.5`。

- 标签以 `/` 分层，例如 `知识/计算机/Go`。可关联中间节点或兄弟分支，不能同时关联某个节点及其后代。
- 移动或重命名标签时，子树和收藏关联一起更新；删除分类只解除关联，收藏保留。
- 评分为 `0` 自动归档，获得系统标签“已归档”。默认列表排除归档，恢复默认评分为 `0.5`。
- 默认按评分、更新时间降序排列。标签筛选包含子分类，多标签条件为 AND。
- 收藏卡片、编辑器、草稿和分享预览均可复制原文。浏览器允许时自动复制，受限时提供手动复制框。
- 编辑内容自动保存为当前浏览器的本地草稿，按用户 ID 隔离。退出不会清除；草稿不包含在服务器备份中。
- 删除收藏为永久操作。

## 链接分享

在收藏菜单选择“分享收藏”，或在分类管理中选择节点后点击“分享此分类及子树”。链接只在创建时显示，请及时复制；可在“分享管理”查看状态和撤销。

默认有效期为 7 天，API 可设置为 1–365 天。接收者必须登录普通账号，管理员不能查看或导入分享。

分享保存创建时的固定快照：

- 单条收藏：包括原文、说明、评分、关联标签及其必要祖先，不包括其他收藏或无关分类。
- 分类子树：包括所选节点、全部后代及空节点，以及关联收藏（含归档）。只保留树内标签，剥离所选节点的祖先路径。例如 `知识/编程/Go` 在分享 `知识/编程` 时变为 `编程/Go`。

接收者选择根目录或已有分类，先预检，再确认导入。合并规则如下：

1. 按映射后的完整标签路径复用节点，异父同名标签保持独立，空节点也会保留。
2. 同一原文合并为一条，标签保留最细后代，兄弟分支并存，说明按片段去重追加。
3. 已有收藏保留接收者的评分与归档状态，新收藏沿用快照评分。
4. 同一位置重复导入不会创建副本，也不会更新无需修改的收藏版本。
5. 数据或目标变化后需重新预检；提交在单一事务中完成，失败整体回滚。

源数据之后的编辑、移动或删除不改变快照。撤销、过期、分享者停用或删除后链接失效，已导入的副本保留。详细算法见[分享设计](sharing-design.md)。

## 智能分析

在设置中填写 Anthropic Messages 兼容服务的 Base URL、Model ID 和 APIKey，再启用分析。例如 Base URL 为 `https://api.anthropic.com`，客户端追加 `/v1/messages`。

分析返回说明和标签，先预览，再应用到编辑器；确认保存前不修改收藏，模型不决定评分。新标签以橙色标记。

完整 HTTP(S) URL 会在服务端抓取一次：3 秒超时、不重试、不跟随重定向，仅接受 HTML/XHTML，解压后最多 2 MiB；阻止私网与保留地址，提取正文最多 40,000 字符，不执行 JavaScript。抓取失败时直接返回错误，不调用模型猜测。分享文案中的嵌入 URL 不会被单独抓取。普通文本直接分析，模型请求最多 60 秒。

## 导入导出

在“导入 / 导出”中导出全部或所选收藏，或选择 JSON 文件进行预检并提交。格式见[导出示例](examples/export.json)。

- `schema_version=1`，`raw_base64` 使用 UTF-8 与标准 Base64。
- 导出包含归档收藏和空分类，不含凭据、会话及本地草稿。
- 重复原文合并标签并保留最细后代；说明以 `\n\n---\n\n` 分隔，完整相同片段不重复追加。
- 文件导入采用导入评分（省略为 `0.5`），与分享导入保留已有评分的规则不同。
- 同文件重复记录按文件顺序处理。非法条目使整个导入失败，单次请求上限 16 MiB。
- 预检后当前用户数据发生变化时，需要重新预检。
